## Дополнительные исправления

- Критерий рекомендации объяснен через скорость и простоту. Варианты показывают переплату; метка рекомендации не обещает минимальную стоимость.
- Удалены неиспользуемые callback-пропсы загрузки и открытия документов.
- Описания ЭДО приведены к `text/plain`, настройки ИИ к `OLLAMA_URL`. Статус исторических research-гипотез отделен от реализации в [реестре возможностей](../product/implementation-status.md).
- Процесс сведен к одной [схеме состояний](../process/application-states.md#4-диаграмма-состояний). Уточнены календарные SLA, права, квоты и границы кредитной линии.
- Формулы, когорты, знаменатели и доли принятия предложений синхронизированы с артефактами. Пустая автоматическая подгруппа, в том числе при наличии только ручных решений, возвращает `null` для своей медианы.
- [Roadmap](../product/roadmap.md) задает следующие шаги: интервью, проверка понимания решения, baseline затрат и сопоставимый пилот.

## Проверки совместимости и границы

Миграция `0001 -> 0002` проверена на отдельной PostgreSQL с существующим черновиком: сумма, статус и сама запись сохранились. Для прежних пакетов без durable-запроса график читается из сохраненного подписанного документа.

Проверка Windows checkout подтверждает переносимость файлов. Полный запуск Docker Desktop на Windows и реальные мобильные устройства отдельно не проверялись. API e2e проверяет HTTP-процесс через nginx; он не заменяет полный браузерный e2e.

Интервью, экономический эффект, независимая валидация модели на реальном потоке, live integrations, юридически значимая подпись и разделение подготовки/подписи между сотрудником и руководителем остаются границами MVP. Нагрузочный прогон, длительная эксплуатация, полный pentest, PITR, экранный диктор и профиль Ollama не входят в подтвержденные результаты этой проверки.
