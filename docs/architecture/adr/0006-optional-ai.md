# ADR-0006. ИИ только как необязательный модуль

Статус: принято. Дата: 2026-10-23.

## Контекст

ТЗ допускает только модели с открытыми весами и требует, чтобы основной сценарий работал без ИИ. Продуктовое решение: [ai-usage.md](../../product/ai-usage.md).

## Решение

* Две функции: резюме заявки для андеррайтера (`POST /api/v1/bank/applications/{id}/ai-summary`) и "Объяснить проще" для клиента (`POST /api/v1/applications/{id}/explain`).
* По умолчанию детерминированный шаблон: резюме собирается из грейда, трех факторов с наибольшим отрицательным и положительным вкладом, причин ручного рассмотрения, расхождений, рекомендации политики и открытых пунктов дозапроса.
* Если задан `OLLAMA_URL` (профиль compose `ai`, модель `qwen2.5:1.5b-instruct` по умолчанию), api обращается к локальной модели с таймаутом 10 секунд. На вход только структурированные поля без ФИО, ИНН и свободного текста клиента. Ответ проверяется (структура JSON, для пояснения: сохранены все метки, нет цифр); числа подставляются после генерации. Любая ошибка: шаблон.
* Результат помечается "Сформировано автоматически", не сохраняется в решении и не влияет на скоринг, политику и статус. Событие `AI_SUMMARY_GENERATED` пишет модель, задержку и признак фолбэка без текста.

## Последствия

* При пустом `OLLAMA_URL` функции работают на шаблонах. Профиль `ai` запускает сервис модели, но включение обращения из API задает `OLLAMA_URL`; реальная Ollama и полезность результата не верифицированы.
* Конкретная модель и ее лицензия указываются в THIRD_PARTY_NOTICES.
