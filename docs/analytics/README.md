# Аналитика: скоринг, политика, синтетические данные, метрики

Раздел аналитика продуктовой команды. Опирается на исследование ([../research/](../research/README.md)) и модель процесса ([../process/](../process/README.md)); результаты использует бэкенд (скоринг, политика, моки, seed) и экран метрик риск-менеджера.

| Документ | О чем |
|---|---|
| [scoring-model.md](scoring-model.md) | балльная карта: методика (биннинг, WoE/IV, логистическая регрессия, PDO), факторы и баллы, грейды A-E, Gini/KS/PSI/калибровка, ограничения синтетики |
| [decision-policy.md](decision-policy.md) | числа кредитной политики и их обоснование, калибровка лимитов нагрузки и ставок, ожидаемые доли исходов, прохождение правил в сценариях S1-S5 |
| [synthetic-data.md](synthetic-data.md) | как сгенерированы данные, 12 демо-компаний, тестовые учетные записи, история заявок, как воспроизвести |
| [metrics.md](metrics.md) | формулы метрик воронки, операционных и риск-метрик по журналу событий, значения на синтетической истории |
