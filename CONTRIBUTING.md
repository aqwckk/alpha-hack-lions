# Как мы работаем

Договоренности команды по работе с репозиторием.

## Язык и стиль текстов

- Документация и тексты интерфейса на русском языке.
- Не используем букву "е" с двумя точками: всегда пишем обычную "е".
- Не используем длинное тире. Вместо него запятая, двоеточие, точка или перестроенная фраза. Короткий дефис в составных словах допустим.
- Код, идентификаторы, имена файлов, коммиты на английском.

## Коммиты

- Очень короткое сообщение на английском в повелительном наклонении: `add scoring engine`, `fix offer expiry`.

## Структура репозитория

| Путь | Что лежит |
|---|---|
| `docs/research/` | исследование, персоны, JTBD, CJM (продукт) |
| `docs/product/` | MVP, user stories, приоритизация, продуктовые решения |
| `docs/process/` | модель кредитного процесса, роли, статусы, диаграмма состояний |
| `docs/architecture/` | архитектура, ADR, модель данных, безопасность |
| `docs/api/` | описание API, OpenAPI, коллекции запросов |
| `docs/testing/` | тестовые сценарии, сценарий проверки для жюри |
| `analytics/` | скоринговая модель, генератор синтетики, отчеты аналитика |
| `services/api/` | основной сервис кредитного конвейера (FastAPI) и воркер |
| `services/integrations-mock/` | симуляторы внешних систем: БКИ, ЕГРЮЛ/ЕГРИП, ФНС, ЭДО, АБС |
| `web/` | веб-интерфейс: кабинет клиента и рабочее место сотрудника банка |
| `deploy/` | конфигурации nginx и окружения |

## Стек

- Python 3.12, FastAPI, SQLAlchemy 2, Alembic, PostgreSQL 17, зависимости через `uv` (`uv.lock`).
- React 18, TypeScript, Vite, зависимости через `npm` (`package-lock.json`).
- Docker Compose как единая точка запуска: `docker compose up --build`.
- Только бесплатные и открытые компоненты. LLM допускаются только с открытыми весами и только как опциональный модуль.
